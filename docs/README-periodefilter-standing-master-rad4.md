# Periodefilter - stående masterfilter + Rad 1-4

Denne versjonen fjerner store masterfilterkort og bruker rullegardinlister.

Struktur:
- Masterfilter
- Land / område
- Objekttype
- Rad 1: hovednivå
- Rad 2: hovedperiode / tema
- Rad 3: underperiode / relasjon / objektspesifikasjon
- Rad 4: alle perioder / konkrete verdier

Poeng:
Rad 1-3 er ikke lenger ødelagt av masterfilterkort. Rad 4 viser alle periodene og eventuelle relevante konkrete relasjonsverdier.
