# Collectium periodefilter test

Versjon: UI/UX 8.6 - Masterfilter 40 + sammenlignende tidslinje.

Denne testen bruker fire rader:

1. Rad 1 = Masterfilterområde
2. Rad 2 = Sammenligningslag
3. Rad 3 = Spesifikasjon
4. Rad 4 = Konkret verdi

Poenget er at perioden ikke bare er en trestruktur. Tidslinjen skal sammenligne parallelle lag:

- Konge/regent
- Nasjonal periode
- Krig/konflikt
- Finans/økonomi
- Signatur/person
- Produsent/utgiver/objekt

Dynamiske felt ligger under Samler / Historie / Finans.
